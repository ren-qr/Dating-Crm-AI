# 已确认的决策

`Staff` 与 `Manager` 对全部会员数据拥有相同的能力和数据范围；差异仅存在于门店、员工、系统设置等非会员模块。

# 需要产品负责人确认的决策

1. 员工是否可直接创建 MatchCase，还是必须由负责人审批？
2. 哪些动作必须有会员明确确认：推荐展示、联系方式交换、约见、录音与转写？
3. Meeting Host 是否录音、保存原始转录多久、谁可读取？
4. Member Advisor 的身份核验方式与人工转接服务时间？
5. `MemberService` 与 `MatchCase` 中约见反馈、意愿和结论的正式写入 Owner？
6. Manager 的系统配置权限是否包括模型配置、政策发布、费用与门店创建？
7. 云端模型的最终数据投影：仅禁止姓名/电话/身份证，还是禁止任何会员字段？
8. 外部通知渠道、日历、场地数据何时接入，以及失败回退策略？
9. V3 首批需要量化的指标：匹配接受率、人工介入率、任务失败率、模型成本、约见完成率。
