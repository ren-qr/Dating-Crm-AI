# 产品边界

## 三个逻辑 Agent

| Agent | 服务对象 | 初始能力 | 禁止能力 |
| --- | --- | --- | --- |
| Staff Copilot | 内部员工 | 已授权的查询、任务发起、经营辅助 | 直接写库、绕过审批 |
| Member Advisor | 会员本人 | 本人资料、偏好草案、约见反馈、人工转接 | 搜索其他会员、读取内部备注 |
| Meeting Host | 已确认约见参与者 | 授权上下文、暖场、节奏控制、会后事件 | 电话、证件、内部评价、负面备注 |

逻辑独立不代表部署三套模型。每个 Agent 必须拥有独立 Profile、Prompt、工具白名单、权限主体、状态 Schema 和停止条件。

## 非目标

- 不让模型直连数据库或执行 SQL。
- 不让 Agent 用自然语言自由互相派工。
- 不把查询、匹配、收费、复盘各做成细碎 Agent。
- 不在第一阶段实现实时语音、自动外联或自动约见。

## 人工边界

AI 可以分析、生成草案、建议下一步和记录经过确认的事实。对外联系、创建正式推荐、收集同意、约见确认、风险结论、收费与任何敏感数据访问均由 Policy 和审批规则控制。
