# 登录与鉴权安全基线

## 范围

- 覆盖第一条闭环：`POST /api/v1/auth/login`、`POST /api/v1/auth/logout`、`GET /api/v1/me`。
- 鉴权方案固定为 NextAuth Credentials，业务接口默认登录后访问。
- 本基线同时作为后续会员、匹配、活动、收费、财务、人员、风控模块的最低安全门槛。

## NextAuth Credentials

- Credentials 登录必须只接受显式字段：`email`、`password`。
- 登录输入必须先校验格式，再进行凭据比对；无效邮箱、空密码、缺字段统一拒绝，不泄露账号是否存在。
- 生产登录必须使用员工表 `Employee.passwordHash` 与安全哈希算法校验，禁止明文密码比较或落日志。
- 会话策略使用 JWT 时，token 只能携带 `employeeId`、角色码、权限码、门店/归属范围等授权所需最小字段。
- `authorize` 返回对象禁止包含 `password`、`passwordHash`、令牌、身份证号、手机号等敏感字段。
- 登出必须使客户端会话失效；如引入服务端会话/黑名单 token，必须支持主动失效。

## RBAC 与资源归属

- 所有 `/api/v1/**` 业务接口默认要求已登录；公开接口必须在契约中显式标注。
- RBAC 权限码以 AGENTS.md 契约为准，后端是最终裁决方，前端仅做显示控制。
- `/api/v1/me` 返回当前员工、角色与权限，用于前端初始化权限状态；返回值必须脱敏。
- 垂直越权：接口必须校验对应权限码，例如人员读取需要 `staff:read`。
- 水平越权：涉及会员、客户、财务、提成、回访、活动等资源时，必须按门店、owner、客户归属或授权范围过滤。
- 权限不足统一返回 `1002`，未登录统一返回 `1001`，不得把权限细节暴露给无权限调用者。

## 敏感字段保护

- 密码、密码哈希、会话令牌、身份证号、联系方式、私有资料地址不得明文返回或写入应用日志。
- 会员证件资料与隐私字段必须加密存储；接口只返回脱敏摘要或受控下载授权。
- 错误响应必须使用统一响应体，避免把异常堆栈、SQL、存储路径、第三方密钥暴露给客户端。
- 审计日志记录前后值摘要，不记录敏感原文。

## 黑名单阻断

- 黑名单命中必须阻断匹配、活动报名/签到、收费、客户归属调整等高风险动作。
- 命中后统一返回错误码 `1005`，并写审计日志，包含操作者、对象、命中规则摘要、请求 ID。
- 黑名单校验必须在业务状态变更前执行；批量操作中每个对象都要独立校验并可追溯。

## 导出与脱敏

- 导出任务必须校验 `export:read` 或 `export:write`，并按模块、时间范围、门店/归属范围过滤。
- 导出内容默认脱敏；确需导出敏感字段时必须有额外权限、审计原因和下载授权。
- 导出文件不得使用可猜测公开地址；下载链接需要短期有效、绑定操作者或一次性授权。
- 导出任务必须幂等，重复请求不得生成不可控的多份敏感数据。

## 审计留痕

- 关键动作必须记录审计：登录成功/失败、登出、权限变更、资料上传、黑名单命中、匹配执行、归属调整、收费、退款、提成核算、导出、回访提醒。
- 审计字段至少包含：操作者、时间、请求 ID、动作、对象类型、对象 ID、结果、前后值摘要、来源 IP/UA 摘要。
- 审计写入失败时，高风险写操作必须失败或进入可追踪补偿队列，不能静默丢失。

## 第一条闭环验收点

- `POST /api/v1/auth/login`：错误凭据返回登录失败，不泄露账号存在性；成功后会话不含敏感字段。
- `GET /api/v1/me` 未登录：返回统一响应体，`code=1001`，`data=null`。
- `GET /api/v1/me` 已登录：返回统一响应体，`code=0`，包含员工 ID、邮箱、姓名、角色、权限，不包含密码/哈希/令牌。
- 权限 helper：缺少权限返回 `1002`；拥有权限且资源归属通过才允许继续。
- 每个响应都有 `requestId` 与 ISO-8601 `timestamp`。
